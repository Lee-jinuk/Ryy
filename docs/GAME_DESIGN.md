# GAME_DESIGN — RYY (Roll Your Yut)

게임의 전체 비전과 기획 의도를 기록하는 문서. 규칙의 확정/미확정 판단 기준은 `GAME_RULES.md`를 따른다.

## 프로젝트 기본 정보

- 게임명: RYY (Roll Your Yut)
- 한글명: 롤 유어 윷
- 장르: 윷놀이 기반 2D 픽셀아트 덱빌딩 로그라이크
- 개발 엔진: Unity
- 개발 형태: 1인 개발
- GitHub: https://github.com/Lee-jinuk/Ryy.git
- 개발 브랜치: `develop` / 배포 기준 브랜치: `main`

## 핵심 방향

윷을 던져 점수를 획득하는 로그라이크 게임.
플레이어는 방울 덱을 직접 구성하고, 매 투척에서 어떤 방울을 사용할지 판단한다.
단순히 좋은 결과가 나오기를 기다리는 게임이 아니라, **제한된 자원으로 확률과 결과를 조작하는 전략 게임**을 목표로 한다.

Balatro는 장르적 참고 작품이지만, RYY는 **방울의 선택과 사용 시점**을 핵심 차별점으로 삼는다.

## 게임 진행 단위

- 투척: 윷을 한 번 던지는 행동
- 라운드: 기본 5회의 투척으로 구성되는 점수 획득 단위
- 판: 여러 라운드로 구성되는 진행 단위

## 방울 덱빌딩

방울은 RYY의 핵심 전략 시스템이다.

- 기본 방울 덱 규모: 12개
- 라운드 시작 전 방울 6개를 무작위로 제시
- 제시된 6개 중 3개를 선택
- 선택한 3개를 해당 라운드의 5회 투척 동안 활용
- 상점에서 방울을 구매하거나 기존 방울을 제거해 덱을 구성

방울의 핵심 재미는 **언제 사용할 것인가에 대한 판단**이다.
개별 능력, 사용 횟수, 소모 방식, 재충전 여부 등은 `GAME_RULES.md`에서 상태를 관리한다.

## 부적 시스템

부적은 방울보다 보조적인 역할을 담당한다.

- 기본 부적 슬롯: 4개 (구상)
- 부적은 빌드 방향을 강화하는 패시브 효과 중심
- 방울은 플레이어가 능동적으로 사용하는 핵심 전략 요소

## 타겟 및 피버 시스템 (Gemini 제안 — 검토 중)

라운드 시작 시 특정 윷 결과 하나를 타겟으로 선택하고, 타겟 적중 시 추가 보상을 받는 구조.

- 타겟 적중: 투척 횟수 차감 없음, 피버 콤보 증가
- 2연속 적중부터 전체 배율에 콤보 배수 적용 (X-Mult 폭발)
- 비타겟: 콤보 초기화 / 백도: 점수 풀 초기화
- 밸런스 방향: 도·개 안정형(최대 8피버) vs 윷·모 고위험 일발 역전형(최대 5피버)

기획 의도: 단순 확률 기다림이 아닌 "어떤 패를 타겟으로 삼을지"를 방울 덱 구성과 연동한 전략 선택지로 만드는 것.
단, 5회 투척·방울 덱빌딩과의 수학적 밸런스 및 플레이 시간 검증이 선행되어야 하며, 현재는 **검토 중**이다.
