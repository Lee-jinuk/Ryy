| 상점 = 보스 소개 화면의 별도 패널 | 확정 | `shopPanel` — ClearPanel 자식 금지(결과 화면과 함께 숨는 구조 방지). 진입 조건: 보스 소개 화면 표시 + GameState.Cleared — **첫 보스전 이전 상점 이용 불가** (사용자 확정). 상점이 열린 동안 보스전 진입·건너뛰기 차단 |
| 상품 구성 = 무작위 후보 | 확정 | `shopOfferCount`(4)종 무작위 추첨 — `effectEnabled` 방울 중 미보유 종류만, 목록 안 종류 중복 없음. 후보 4종 미만이면 가능한 수만 표시 |
| 상품 목록은 보스 구간 동안 유지 | 확정 | 2026-10-21 사용자 확정 — 상점을 닫아도 목록 유지, 닫기·재진입으로 무료 갱신 불가. 다음 보스 소개(`ShowBossSelect`)에서 목록·비용 초기화 |
| 상점 리프레시 = 유료 | 확정 | 비용 2냥부터 성공마다 2배 (2→4→8→16…, `ShopConfig.refreshBaseCost`/`refreshCostMultiplier`). 구매 완료 칸 포함 전체 재구성, 판매한 종류도 후보에 복귀. 잔액 부족·후보 없음이면 차감 없이 실패. 성공 횟수·비용은 보스 구간 누적 — 보스 전환 시 초기화 |

| 재구매한 방울의 발동 횟수 | 확정 | 판매 후 재구매하면 새 인스턴스 — 발동 횟수는 새 상품 기준으로 초기화 (2026-10-21 사용자 확정) |
| 방울 가격 = 통일 구매 20냥·판매 10냥 | 확정 | `BellData.buyPrice`/`sellPrice` — 방울별 개별 조정 가능한 구조로 구현 |

| 윤회령 재투척 기회 보존 확률 | 확정 | **5%**(`chance`) — 20종 체계에서 7%→5% 변경, 기본·재기부 특별 재투척 모두 적용, 실제 실행 시점에만 추첨 — 구현 완료 (2026-10-26) |

### 방울 20종 체계 (2026-10-26 사용자 지시서 — 전 종 구현 완료, Unity Play 검증 대기)

방울은 아래 **20종으로 한정**한다. 기존 4종은 이름·수치 변경 후 효과 재사용(수령→청류령 / 목령→잔향령 / 족쇄→속박령 / 천운→윤회령 7%→5%), 제거 10종은 재추가하지 않는다. 장착 최대 4개·종류당 1개·구매 20냥·판매 10냥·고정 슬롯 UI·방울+복주머니 혼합 상점·보스 전환 유지·새 런 초기화·효과 발동으로 소멸 없음은 그대로 유지한다. 20종 전부 `effectEnabled: 1` — 상점에서 전 종 구매 가능.

**최종 피해 공식** (2026-10-27 확정 — 가산 우선 구조): 기초 피해 = 윷 기본점수 × 성장 반영 윷 배율. 전체배율 = **(기본 전체배율 + 윤환령 런 누적 완주 + 부적 가산 + 잡기 가산 + 방울 가산 + 말판 가산 + 상성 가산) × 곱연산 부적(결과별 부적 × 피해 부적 곱) × 잡기 × 곱연산 방울 × 말판 × 보스 상성**. 가산 효과 없으면 합계는 기본값만 남고, 곱연산 효과 없으면 해당 배율은 ×1 — 비상성 보스 상성도 ×1. 가산/곱연산 구분은 데이터 — 부적 `totalMultOp`(Add/Multiply)·방울 `totalMultAdd`(방울가산)/`tileMultAdd`(말판가산). 잡기가산·상성가산은 현재 적용 효과 없는 예약 항. 기존 효과는 전부 곱연산 유지(×2·×4를 +N으로 바꾸지 않음), 가산 배정은 사용자 지정에만. 필수 예시(기초 피해 120·불 말판 ×2·기본 전체배율 1): 기본 불 공격 240 / 결단령 (1+2)×2=6 → 720 / 폭염령 (1+1)×2=4 → 480 / 결단+폭염 (1+2+1)×2=8 → 960 / 위 둘+화염령 발동 (1+2+1)×2×2=16 → 1,920.

**최초 투척 결과 확률 보정** — 기준은 실제 4개 윷의 면 분포(도 25·개 37.5·걸 25·윷 6.25·모 6.25). 장착 효과를 모아 한 번 계산(장착 순서 무관): 일반 경우 대상 +N%p, 남은 확률을 비대상 기본 비율로 분배. 예외(전원 대상 또는 대상 합계 ≥100%): 전체를 함께 정규화 — 비대상 강제 0 없음. 결과 선추첨 후 해당 앞면 개수의 면 조합을 균등 배치해 결과=면 일치. 재투척은 실제 면 판정·보정 미적용. `YutRollManager.BuildInitialResultWeights` + `YutThrowSession.RollWeightedFaces`.

**제거된 방울 10종**: 도걸방울·윷령방울·화령방울·지령방울·도깨비방울·개화방울·걸음방울·모령방울·청개구리방울·재복방울 — 20종 체계에서도 재추가하지 않는다. 윷·속성 런 성장 저장소는 이미 삭제됨.

**미확정**: 수룡부와 청류령의 동시 적용·소모 우선순위 — 수룡부 비활성 유지, 사용자 결정 대기.

#### 확률 강화 공통 규칙 (윷 결과·속성 발생 동일 — `YutRollManager.ApplyPercentBonuses` 단일 소유)

- 대상 결과에 강화량을 %p로 더하고, 증가한 만큼 비대상 결과에서 **기존 비중에 따라 비례 차감**.
- 여러 강화·방울 효과는 함께 모아 한 번에 계산 — 적용·장착 순서에 무관하게 동일 결과.
- 모든 결과가 증가 대상이거나 비례 차감을 적용할 수 없으면, 기본 확률 + 증가분 전체를 합계 100%로 정규화.
- 음수·NaN·총합 오차 방지. 기본 낙 판정은 별도 유지. 표시 반올림과 추첨 정밀도 구분.
- 윷 결과: 최초 투척에만 적용, 최초 투척 결과와 표시된 4개 면 조합은 항상 일치 (결과 추첨 → 면 표시 순서). 방울 보정(걸윷·쌍개·극단)은 점괘와 별개 버킷으로 동시 적용.
- 예시 (도 +5%p): 도 25→30 / 개 37.5→35 / 걸 25→23.3333 / 윷·모 6.25→5.8333

#### 재투척 앞·뒷면 강화 규칙

- 최종 앞면 확률 = `Clamp(기본 앞면 확률 + 앞면 누적 − 뒷면 누적, 20%, 80%)`, 뒷면 = 100% − 앞면.
- 기본 앞면 확률 = 양면령 미장착 50%, 장착 시 해당 방울 설정값(현재 70%).
- 선택 1회당 해당 면 누적 +2%p. 최초 투척 미적용, 기본·재기부 특별 재투척 모두 적용.
- 합산 후 마지막에 제한 — 양면령 포함 각 면 최대 80%. 양면령 판매·재장착 시 현재 강화량 기준으로 재계산. 공령명 확률 증폭 대상 아님.

#### 상점 구매 할인 규칙

- 구매가격 = `Ceil(정가 × (1 − 적용 할인율))` — 정가 자체 미변경, 할인된 구매가 계산.
- 누적 획득 할인율(`ShopDiscountPending`, +5%p/회)과 현재 적용 할인율(`ShopDiscountPercent`)을 구분 — 획득한 상점에는 미적용, **다음 보스 처치(보상 지급 완료 지점) 후 이용하는 상점부터** 적용. 상점 닫기·재진입·새로고침·점괘 창 종료·보스 건너뛰기로는 활성화되지 않는다.
- 대상: 방울·복주머니 구매가 모두. 새로고침 비용 할인 없음. 판매가는 기존 개별 설정값 유지(정가 비율 자동 변경 없음).
- 최대 할인율 50%(`ShopConfig.shopDiscountMaxPercent`). 상품 표시·구매 가능 판정·실제 차감은 `ShopManager.PriceFor` 단일 조회 공용.
- 예시: 정가 20냥·5% → 19냥 / 정가 19냥·5% → 19냥(올림) / 정가 20냥·50% → 10냥. 새 런에서 누적·적용 모두 초기화.
