## 2. 방울 장착·상점·경제 (2026-10-20 재정의)

| 규칙 | 상태 | 비고 |
|---|---|---|
| 방울 = 최대 4개 보유·장착하는 지속 장비 | 확정 | 종류당 1개 제한 (중복 장착 불가). 전투 화면·상점 화면에서 이름·설명·남은 발동 횟수 표시 |

| 소멸·판매된 방울의 효과·표시 잔류 없음 | 확정 | 인스턴스만 제거 — 그 방울이 쌓은 런 성장(윷 배율·속성 공격력)은 판매·소멸 후에도 런 종료까지 유지 (사용자 확정) |

| 상점 = 보스 소개 화면의 별도 패널 | 확정 | `shopPanel` — ClearPanel 자식 금지(결과 화면과 함께 숨는 구조 방지). 진입 조건: 보스 소개 화면 표시 + GameState.Cleared — **첫 보스전 이전 상점 이용 불가** (사용자 확정). 상점이 열린 동안 보스전 진입·건너뛰기 차단 |
| 상품 구성 = 무작위 후보 | 확정 | 상점 진입마다 `shopOfferCount`(기본 4)종 무작위 추첨 — `effectEnabled` 방울 중 미보유 종류만. 판매한 상품은 이번 진입에서 재구매 불가 |
| 방울 가격 = 통일 구매 20냥·판매 10냥 | 확정 | `BellData.buyPrice`/`sellPrice` — 방울별 개별 조정 가능한 구조로 구현 |
| 구매·판매 = 원자적 거래 | 확정 | 잔액 부족·장착 만석·중복 종류·판매 완료·없는 방울이면 거래 실패 + 상태 보존. 돈 차감과 획득/제거는 한 번에 처리 — 연타 중복 거래 차단 |
| ~~방울 덱 12개·라운드 전 6택3 선택 구상~~ | 대체됨 | 2026-10-20 장착·상점 시스템으로 대체 — 라운드별 방울 선택 규칙 폐기 |
| 천운방울 재투척 기회 보존 확률 | 미확정 | 제안값 20%는 미확정 — `effectEnabled: 0`으로 상점 풀·효과 모두 비활성 |
| 재복방울 세부 | 부분 미확정 | 확정: 보스 **원래 약점** 속성 칸 공격 판정당 1냥 (정산당 1회, 연출·스킵 중복 지급 없음). 미확정: 청개구리 변경 상성 기준 여부·최종 피해 0일 때 수입 여부 — 현재 원래 약점 기준·피해 무관 지급으로 임시 적용 |
| 족쇄방울 최소 이동 | 확정 | 보스 이동 −1칸, **최소 1칸 보장** — 봉쇄부의 0칸 이동을 되살리지 않음 (사용자 확정) |
| 청개구리방울 vs 잡기 강제 상성 | 확정 | **청개구리 우선** — 장착 중 강점 칸 잡기도 ×3 적용 (사용자 확정) |
| 재복방울 판매·재구매 시 횟수 처리 | 미확정 | 발동 한도가 있는 방울을 판매·재구매할 경우 남은 횟수 처리 규칙 확정 필요 |

### 방울 12종 정의 (BellDatabase 에셋 — 2026-10-20)

윷 배율 성장형 5종 — 해당 결과를 최종 확정할 때마다 그 윷의 런타임 기본 배율 +0.5 (최대 5회 = 총 +2.5, 소멸 후 성장 유지):

| 방울 | 조건 | 방울 | 조건 |
|---|---|---|---|
| 도깨비방울 | 도 확정 | 윷령방울 | 윷 확정 |
| 개화방울 | 개 확정 | 모령방울 | 모 확정 |
| 걸음방울 | 걸 확정 | | |

속성 공격력 성장형 3종 — 해당 속성 칸에 최종 착지할 때마다 그 속성 전체의 런타임 기본 공격력 +5 (최대 10회 = 총 +50, 소멸 후 성장 유지). 진격부·후퇴부 보정 후 최종 착지 칸 기준, 지나간 칸에는 미발동:

| 방울 | 조건 |
|---|---|
| 화령방울 | 불 칸 착지 |
| 수령방울 | 물 칸 착지 |
| 목령방울 | 풀 칸 착지 |

특수·경제형 4종:

| 방울 | 효과 | 상태 |
|---|---|---|
| 족쇄방울 | 보유 중 보스 이동 거리 −1칸 (최소 1칸) | 확정 |
| 청개구리방울 | 원래 강점 속성 상성 ×3·나머지 공격 속성 ×0.5 — 잡기 강제 ×2보다 우선 | 확정 |
| 천운방울 | 개별 재투척 시 확률로 기회 미소모 | 확률 미확정 — 비활성 |
| 재복방울 | 원래 약점 속성 칸 공격 판정당 +1냥 | 부분 미확정 — 임시 적용 중 |
