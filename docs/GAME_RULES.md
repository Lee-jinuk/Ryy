## 5. 점수 계산

| 규칙 | 상태 | 비고 |
|---|---|---|
| 투척별 독립 정산: `ThrowScore = BasicScore × Multiplier` → `TotalScore`에 1회 합산 | 확정 | 기존 (베이직 풀 × 누적 배율) 방식 폐기. 투척마다 베이직·멀티플 재계산, 이전 투척 임시값 미누적 |
| ~~윷별 베이직 기준값~~ → ~~도착 칸 점수 + 완주 + 강화치~~ → 베이직 = 도착 칸 기본 공격점수 | 확정 | 2026-10-18 속성 말판 전환으로 완주·강화치 가산 폐기 (8절). 윷 기본 베이직 10~50 폐기 유지 |
| **최종 데미지 = 도착 칸 기본 공격점수 × 보스 상성 배율 × 윷 결과 배율** | 확정 | 2026-10-18 보스 상성 도입. START·땅·쇠는 상성과 무관하게 0. 소수 배율(×0.5)은 float 곱셈 후 반올림 — 정수 나눗셈 0 처리 금지 |
| 보스 상성: 불·물·풀을 무작위로 섞어 기본 100% / 약점 200% / 강점 50%에 하나씩 배정 | 확정 | 같은 속성 중복 배정 없음. 보스별 런당 1회 생성(첫 소개·사용 시점) 후 저장 — UI 갱신·전투 진입·건너뛰기로 재추첨 없음. 새 런에서 새 생성. 원본 `BossData` 미변경 (런타임 `BossAffinity` 분리) |
| 윷별 멀티플: 도 ×2 / 개 ×3 / 걸 ×4 / 윷 ×5 / 모 ×6 | 확정 | GPT 지시값 |
| 윷별 영구 스탯 강화 구조 (주술 대비) | 확정 | 런타임 `yutStats` 복사본 사용 — `UpgradeYutStat()`으로 강화 시 기본 데이터 오염 없음. `basicBonus`는 신규 공격 공식에 미적용(예약 필드), `mult`만 적용됨. 강화 UI 미구현 |
| 효과 적용 단계 기록 (`ScoreEffectStep`) | 확정 | 부적·방울·주술 발동 연출용 — 원인/식별자/표시명/대상/연산(+·×)/전·후 수치/증가량/순서 기록 |
| 백도 기본 처리 방식 | 확정 | 보스 1~5: 누적 점수(`totalScore`)에서 차감 / 보스 6~10: 누적 점수 초기화 (4절 참조). 구 `roundScore`(판별 누적)는 라운드 폐지로 삭제 — 보스전 내 `totalScore`와 동치였음. 차감량은 미확정 테스트값 |
| 보스 목표 점수 = 선택 보스 최대 HP (`GoalScore`) | 확정 | 테스트 보스 5명: 1000/2000/3000/4000/5000 (이름·수치 전부 임시). 말판 방식으로 점수 상승 → 밸런스 조정 대상이나 임의 변경 안 함 |
| 보스 현재 체력 = `Max(0, GoalScore − TotalScore)` | 확정 | 별도 HP 상태 필드를 두지 않고 계산값으로 표시 (`bossCurrentHPText`, 숫자만). 누적 피해는 `totalScoreText`, 최대 체력은 `goalScoreText`. 연출 중에는 표시용 `displayTotal` 기준으로 갱신되어 종료·스킵 후 실제 체력과 일치 |
| 보스 클리어 조건: `TotalScore ≥ GoalScore` | 확정 | 정산 연출 종료 후 판정 (스킵해도 동일). 마지막 투척으로 처치하면 클리어가 게임오버보다 우선 |
| 게임오버 조건: 기본 투척 5회 소진 후 목표 미달 | 확정 | 클리어 판정을 먼저 수행하므로 5회째 처치는 클리어 처리 |
| 보스 특수능력: 낙 확률 +2%p (현재 전 보스 공통) | 보류 | **신규 윷 4개 면 조합 방식에 적용 불가 — 현재 발동하지 않음** (2026-10-18). 새 작동 방식·대체 능력은 미확정 — 임의 대체 금지. `abilityDescription` 표시는 데이터 그대로 유지 |
| 클리어 후 다음 관문은 수동 진행 | 확정 | ClearPanel의 '다음 관문' 버튼(`GoToNextBoss`)으로만 보스 N → N+1 이동. 클리어 즉시 자동 이동 없음 |
| 다음 관문 진입 시 초기화 | 확정 | TotalScore·ThrowScore·Basic·Mult·투척 횟수(5회로 재설정)·말 위치(BoardTile_01)·완주·말판 재배치·방울 칸 재배치·임시 방울 전부 초기화, 새 보스 목표·능력 적용 |
| 런 전체 성장 요소는 관문 이동 시 유지 | 확정(구조) | 엽전·윷 강화·부적·영구 방울 등 — 미구현이므로 유지 대상만 구조로 확정, 임의 구현 금지 |
| 보스 5 클리어 = 최종 클리어 | 확정 | 다음 관문 버튼 숨김 + '최종 클리어' 메시지(`clearMessageText`). 보스 선택 복귀 버튼은 유지 |
| 보스 진행은 순차 소개 방식 | 확정 | 보스 5명 직접 선택 UI 폐기(2026-10-18). 소개 화면에는 진행 순서의 보스 한 명만 표시, '다음'(`EnterBossBattle`) = 전투 시작 / '건너뛰기'(`SkipBoss`) = 전투 없이 다음 보스 소개. 게임 시작·클리어 후 다음 관문이 같은 UI 공용 사용 |
| 보스 건너뛰기 | 확정 | 소개 화면에서만 사용. 다음 보스가 있으면 소개 대상을 한 명 전진 — 전투·보상·비용·처치 기록 없음. 마지막 보스는 건너뛰기 불가(버튼 자동 숨김). 전투·정산·게임오버 중 실행 불가. 반복 등장·HP 증가 규칙은 미확정(새로 확정하지 않음) |

## 7. 타겟 및 피버 시스템 (폐기 — 2026-10-18)

**2026-10-18 사용자 승인으로 전체 제거됨.** 타겟 선택 단계·타겟 적중 무료 투척·피버 콤보/배율·관련 표시를 전부 폐기했다. 보스전 진입 시 타겟 선택을 거치지 않고 바로 투척 가능하며, 일반·저주 결과 모두 투척 1회를 소모한다. 이력은 변경 이력의 이전 항목 참조.
