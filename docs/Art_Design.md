# 📜 RYY (Yut-nori Deckbuilder) 프로젝트 구조 및 아트/데이터 규격서

## 1. 게임 코어 컨셉 & 화면 레이아웃
- **장르:** 한국 전통 민속/무속 테마 기반의 로그라이크 윷놀이 덱빌딩
- **핵심 루프:** 윷 투척 ➔ 결과(도/개/걸/윷/모/빽도/낙) 판정 ➔ 유물(방울) 패시브 발동 ➔ 부적(카드) 사용 및 타겟 지정 ➔ 말 이동 및 점수 정산

### 🖥️ 메인 UI 영역 및 슬롯 매핑
1. **상단/좌측 (패시브 유물 영역 - `BellSlot`):** 획득한 무당 방울 및 유물이 나열되는 슬롯. 조건 충족 시 딸랑거리며 효과 발동.
2. **중앙 (메인 보드 & 투척 영역):** 29칸 원형/사각형 윷판 노드와 윷가락 4개가 던져지는 연출 공간.
3. **하단 (핸드/소모품 영역 - `TalismanSlot`):** 플레이어가 보유한 부적 카드 슬롯. 클릭 시 즉시 발동하거나 타겟 선택 모드로 진입.
4. **오버레이 (타겟 지정창 - `TargetSelectPanel`):** 특정 윷가락, 윷말, 혹은 보드 칸을 지정해야 하는 부적 사용 시 활성화되는 선택 패널.

## 2. 픽셀아트 에셋 규격 및 파일 명명 규칙 (Naming Convention)
모든 스프라이트는 `Assets/Sprites/` 하위 폴더에 카테고리별로 분류하며, AI 및 스크립트가 자동 매핑할 수 있도록 **스네이크 표기법(`소문자_조합`)**과 **고정 접두사(Prefix)**를 사용한다.

| 카테고리 | 폴더 경로 | 캔버스 크기 (px) | 접두사 (Prefix) | 파일명 예시 | 용도 및 연결 UI |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **방울/유물** | `Sprites/Relics/` | **`32 x 32`** | `bell_`, `relic_` | `bell_gold.png`, `relic_bokjori.png` | `BellSlot`에 장착되는 패시브/액티브 아이템 |
| **부적 카드** | `Sprites/Talismans/` | **`32 x 48`** | `talisman_` | `talisman_reroll.png`, `talisman_fire.png` | `TalismanSlot`에 들어가는 세로형 부적 |
| **윷가락** | `Sprites/Yuts/` | **`16 x 48`** (또는 `32x32`) | `yut_` | `yut_normal_front.png`, `yut_lightning_back.png` | 앞면(평평함)/뒤집힌면(둥근 등) 상태 구분 필수 |
| **윷말/노드** | `Sprites/Board/` | **`16 x 16`** | `piece_`, `node_` | `piece_rabbit_red.png`, `node_spot.png` | 윷판 위의 말, 길목 점, 도깨비불(방해물) |
| **화폐/소형** | `Sprites/Icons/` | **`16 x 16`** | `ico_` | `ico_coin_yeopjeon.png`, `ico_buff_luck.png` | 상점 엽전, 상태이상, 작은 표식 아이콘 |
| **UI 프레임** | `Sprites/UI/` | **`24 x 24`** (9-Slice) | `ui_` | `ui_panel_wood.png`, `ui_btn_select.png` | `TargetSelectPanel` 배경, 버튼 테두리 (모서리 8px 분할) |

## 3. 도트 드로잉 5대 원칙 (미술 초보용 고정 공식)
1. **팔레트 고정:** 원색 사용을 금지하며, 지정된 단일 팔레트(예: `Endesga 32` 또는 전통 오방색 기반 커스텀 팔레트) 내에서만 색을 추출한다.
2. **외곽선 (Outline):** 완전한 검은색(`#000000`)은 배경과 섞이므로, 아주 어두운 고동색/남색(`#181425`)을 기본 테두리 색으로 쓴다.
3. **고정 광원 (↖):** 모든 에셋의 빛은 **왼쪽 위**에서 비춘다.
   - 위쪽/왼쪽 테두리 안쪽 1px = 기본색보다 **한 단계 밝은 색 (하이라이트)**
   - 아래쪽/오른쪽 테두리 안쪽 1~2px = 기본색보다 **한 단계 어두운 색 (그림자)**
4. **여백 확보:** `16x16`이나 `32x32` 캔버스 끝까지 꽉 채워 그리지 않고, 상하좌우 **최소 1~2px의 투명 여백**을 남겨둔다. (유니티에서 외곽선 이펙트나 흔들림 애니메이션을 줄 때 잘리지 않기 위함)
5. **상태 구분 (윷가락):** 윷가락은 한눈에 결과가 읽혀야 하므로, **배(평평한 면)는 밝은 나무색 + 붉은/검은 X자 문양**, **등(둥근 면)은 어두운 갈색 + 나무 결**로 명도 차이를 확실하게 둔다.

## 4. 유니티(Unity) 연동 및 연출 규칙
1. **Sprite Import 기본값:**
   - `Pixels Per Unit (PPU)`: **`16`** (16px = 유니티 1 Unit 기준)
   - `Filter Mode`: **`Point (no filter)`**
   - `Compression`: **`None`**
2. **애니메이션 최소화 (코드 연출 지향):**
   - 도트 프레임을 여러 장 그리는 노가다를 피하고, 에셋은 **단일 정지 이미지(1 프레임)** 위주로 제작한다.
   - 타격감과 생동감은 유니티 코드(DOTween 또는 코루틴)를 통한 **크기 튕김(Scale Punch), 회전 흔들림(Shake Rotation), 색상 점멸(Flash)**로 구현한다.
   - 예외적으로 '도깨비불'이나 '횃불' 등 가만히 있어도 일렁이는 오브젝트만 2~3프레임 스프라이트 시트(`_sheet.png`)로 제작한다.
